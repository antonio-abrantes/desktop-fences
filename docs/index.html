The usual clones leave duplicates

DeskFrame, NoFences, and OpenFences float shortcuts in a window while the original icons stay on the desktop. You get two of everything.

Real icons, now with safer custody

DesktopFences keeps each item in a stable store, restores it on drag-out, pause, or exit, and remembers where it belonged. Hide is never permanent.

What MVP 3 delivers

The same native fences, rebuilt around safer desktop custody and recovery.

Real icons, not mirrorsFiles, folders, shortcuts, and supported system icons live in the fence without duplicates on the desktop.
Drag and organizeSingle or multi-select, reorder, move between fences without moving the payload, or drag out near the cursor.
Crash-safe stateStable item identity, transactional moves, atomic layout saves, backup, and deterministic startup recovery.
One-click recoveryA separate recovery app copies items back safely, preserves the store, and never overwrites desktop files.
Positions rememberedPause and exit return icons to their original places. Explorer resolves a spot if it is already occupied.
Native desktop behaviorSurvives Explorer restarts and Win+D. Multiple fences, snap, colors, PT/EN, tray, and Windows startup remain built in.
